# AA Desk

AA Desk — одно приложение Windows в трее для небольших утилит работы с файлами. Основа — [Downloads Stack](https://github.com/Vivoxti/Downloads-Stack-For-Windows-Tray) от Vivoderin, upstream `bfb316ae348347821b943d4108e2396ff989bd74`. История upstream сохранена в Git; оригинальная MIT-лицензия находится в `LICENSE`. Изменения AA Desk ведутся в ветке `aa-desk/bootstrap`.

## Состояние 0.1.0

- Один процесс, один значок трея и единое окно настроек.
- «Список загрузок» и SmartExplorer включаются в раскрывающихся карточках настроек. Выключение списка останавливает наблюдение за папками; выключение SmartExplorer освобождает глобальную клавишу. В карточке SmartExplorer можно отключить использование последнего пути.
- SmartExplorer: `Win+Shift+E` открывает папку одного скопированного файла с выделением файла либо скопированную папку. Текстовый полный путь работает так же. Если буфер не содержит корректного пути, используется последний существующий путь; если его нет, открывается обычный Проводник. Буфер не изменяется. Команда есть и в меню трея. Конфликт клавиши показывается в настройках.
- Значки AA Desk заменены для приложения и двух состояний трея. Чтобы изменить их, отредактируй `src/DownloadsStack/Assets/aa-desk.svg` и запусти `python tools/create-aa-icons.py`: скрипт обновит `app.ico`, `tray.ico`, `tray-active.ico` и PNG. Для генерации нужны CairoSVG и Pillow; готовые файлы уже лежат в репозитории и обычная сборка не требует Python.
- Отдельные AppUserModelID, mutex/pipe, папка данных, автозапуск, ярлыки и MSI UpgradeCode не пересекаются с Downloads Stack.
- Версия задаётся в `src/DownloadsStack/DownloadsStack.csproj`; MSI, setup EXE и portable-архив получают её из одного места.
- Настройки показывают текущую версию, проверяют релизы `afinogenovdsgn/aa-desk` вручную и при запуске не чаще раза в сутки. При наличии нового релиза кнопка скачивает setup EXE, сверяет SHA-256 с отдельным файлом релиза и запускает установщик. До первого опубликованного релиза проверка сообщает, что релизов нет.

Внутреннее имя сборки и namespace пока остаются `DownloadsStack`: на них завязаны WPF-ресурсы исходника. Внешнее имя приложения и установщика — AA Desk.

## Сборка

Нужен .NET SDK 10.0.201 или совместимый latestFeature по `global.json`. SDK можно поставить в `.tools/dotnet`; скрипт упаковки найдёт его автоматически. Выполнить `dotnet test DownloadsStack.slnx -c Release`, затем `./scripts/package.ps1`. Скрипт выпускает самодостаточные `AADesk-<version>-setup-win-x64.exe`, соответствующий `.sha256`, `.msi` и `-portable-win-x64.zip` в `artifacts/`. Публиковать EXE и `.sha256` в одном GitHub Release с тегом `v<version>`. Для установщика скрипт восстановит локальный WiX 6.0.2 и его расширения. Установщик собран без цифровой подписи.

## Следующие функции

В отдельном прототипе `00 Materials/DownloadsStack-SmartExplorer/references/SmartExplorerTray-prototype.cs` есть черновые действия `last`, `open`, `run` и редактируемые сочетания. Они ещё не перенесены в модуль AA Desk. Копирование пути выбранного файла из Проводника и «папка-якорь» в диалогах сохранения Photoshop также требуют отдельной реализации и проверки в целевых приложениях. Их нельзя считать свойствами версии 0.1.0. Подробнее о происхождении и первоначальном сценарии — в `00 Materials/DownloadsStack-SmartExplorer/README.md`.

Новые утилиты добавляются как модули внутри одного приложения: собственная логика и состояние, общий трей и единые настройки. Внешнюю систему плагинов вводим, когда понадобится независимая поставка модулей.
